# Контекст · анализ транзакций 1С

Локальный инструмент на HTML, CSS и JavaScript. Не требует установки, подключения к 1С, сервера или доступа к интернету.

## Запуск

Откройте **`dist/Контекст1С.html`** в Chrome или Edge. Это самодостаточный HTML со встроенными JS и CSS; его можно переносить отдельно. Выберите **каталог одной выгрузки конфигурации**, вставьте контекст из той же версии конфигурации и нажмите **Построить контекст** (или Ctrl+Enter).

Для доработок есть отдельные исходники: `dist/index.html`, `engine.js`, `app.js`, `demo.js`, `styles.css`. При запуске `index.html` эти файлы должны лежать рядом.

После выбора каталог выделяется зелёным, показываются отметка «Каталог выбран», доступный браузеру путь и число найденных модулей. Пустая папка или ошибка доступа показываются прямо в этом блоке. Браузер скрывает абсолютный путь Windows: вместо выдуманного префикса отображается `…\ИмяПапки`.

Выбор каталога — стандартное разрешение браузера на чтение файлов. Страница читает их локально, без отправки на сервер. Текст читается только у модулей из стека; остальные файлы нужны только для индекса путей. После перезагрузки страницы каталог нужно выбрать повторно.

В браузере есть кнопка **Открыть пример**: она подставляет отдельные демонстрационные исходники и стек из трёх вызовов.

## Выбор ZIP и распаковка рядом

Вместо каталога можно нажать **ZIP** и выбрать архив. Распаковка запускается автоматически; отдельной кнопки распаковки нет. При первом обращении браузер запросит доступ к папке, **в которой находится этот ZIP**. Диалог сразу откроется в папке архива. После разрешения доступа инструмент распакует ZIP и автоматически выберет полученный каталог. Для следующих архивов из той же папки уже выданный доступ используется повторно, пока страница открыта.

Браузер не предоставляет путь к родительской папке по выбранному файлу, поэтому выбор папки обязателен. Инструмент сравнивает имя и содержимое выбранного архива с файлом в указанной папке, создаёт рядом новую папку с именем ZIP без расширения и распаковывает файлы. Если имя занято, используется `Имя (1)`, `Имя (2)` и т. д. После успешной распаковки полученный каталог выбирается автоматически; отдельно выбирать его не нужно. Абсолютный путь браузер не раскрывает, поэтому интерфейс показывает имя родительской папки и путь внутри распаковки.

Запись на диск использует File System Access API в Chrome / Edge. В браузере без этой возможности показывается сообщение; обычный выбор каталога продолжает работать. Перезагрузка страницы требует повторного выбора источника.

Поддерживаются ZIP и ZIP64 со сжатием Deflate или без сжатия, имена UTF-8, Unicode Path Extra Field и традиционная кодировка CP866. Распаковка потоковая: весь архив и все распакованные данные не загружаются одновременно в память. Для каждого файла проверяются размер и CRC32. Архивы с паролем, многотомные архивы, ссылки и небезопасные пути отклоняются. При сбое неполная папка сохраняется для проверки, но не выбирается как источник; исходный ZIP не изменяется.

## Контекст

Поддерживаются обе записи:

```text
ОбщийМодуль.ИмяМодуля.Модуль:42:ВыполнитьОперацию();
{Документ.Заказ.МодульОбъекта(18)}: ОбработатьДанные();
```

Вызовы можно разделять переводами строк либо точкой с запятой. Номер строки начинается с 1. Обязателен текст строки — без него проверить соответствие конфигурации невозможно.

Для форм принимаются окончания `.Форма`, `.Модуль` и `.МодульФормы`, а также запись без последнего имени модуля. Поддерживаются русские имена типов метаданных и их английские эквиваленты. Имена объектов и модулей сопоставляются без учёта регистра.

## Форматы выгрузки

Распознаются автоматически по структуре файлов согласно разделу [2.17.3. Форматы выгрузки](https://its.1c.ru/db/v851doc#bookmark:dev:TI000001893):

- Иерархическая: `CommonModules/Имя/Ext/Module.bsl`, `Documents/Имя/Ext/ObjectModule.bsl`, `Catalogs/Имя/Forms/Форма/Ext/Form/Module.bsl` и другие типы модулей.
- Линейная: `CommonModule.Имя.Module.txt`, `Document.Имя.ObjectModule.txt`, `Catalog.Имя.Form.Форма.Form.Module.txt`.
- Корневые модули конфигурации: управляемое / обычное приложение, внешнее соединение, сеанс.
- Файлы в UTF-8 (с BOM или без него) и UTF-16 с BOM. Бинарные и защищённые модули не разбираются.

Если каталог содержит несколько файлов одного и того же модуля, инструмент показывает ошибку неоднозначности и список путей. Он не выбирает версию по совпадению текста строки.

## Результат

В таблице: модуль, исходная строка вызова, номер строки, признаки транзакции, явной транзакции внутри неявной, попытки, отмены транзакции и вызова исключения; состояние сопоставления с исходниками.

При выборе строки открывается полный метод с номерами строк, подсветкой и стрелкой на строке контекста. Есть режимы **Весь метод**, **Ключевые строки**, **С обработчиками**, переход к вызову, копирование метода и экспорт таблицы в CSV. По строкам таблицы можно перемещаться клавишами ↑ / ↓, Home / End.

При отличии текста от строки в исходнике показывается **Несоответствие конфигураций** и два текста для сравнения. Игнорируются только пробелы по краям текста; регистр, внутренние пробелы и литералы сохраняются. Сдвиги строк, поиск похожего вызова и автоматическая подмена номера строки не допускаются. Для строки с ошибкой признаки не вычисляются; корректные кадры остаются доступными.

## Интерпретация признаков

Это статический анализ текста, аналогичный обработке, а не выполнение BSL:

- **Транзакция:** до выбранной строки есть начало, а после неё — фиксация или откат; либо выбрана сама строка начала транзакции; либо обнаружен признак неявной транзакции (вызов `.Записать()` / `.Write()`, `ЗаписатьВФорме()` или метод `ОбработкаПроведения` / `Posting`).
- **Внутри неявной:** одновременно обнаружены признаки явной и неявной транзакции.
- **Попытка:** строка находится внутри блока `Попытка / Исключение / КонецПопытки`.
- **Отмена / Вызов исключения:** соответствующая операция есть в обработчике охватывающей попытки. Строка самого отката также отмечается как отмена.

Комментарии и строковые литералы не дают ложных ключевых слов. Для русских и английских конструкций языка анализ одинаков. Соседний обработчик другого блока не приписывается выбранному вызову. Условия, циклы, директивы компиляции, динамический код, фактический тип объекта при `.Записать()` и состояние транзакции у вызывающей стороны не вычисляются. Поэтому признаки показывают места для исследования, а не доказывают состояние сеанса 1С.

## Проверки и разработка

Зависимостей нет. При установленном Node.js:

```text
npm test
npm run build
npm start
```

Предпросмотр запускается только на `127.0.0.1:8765`. Для обычной работы он не нужен: достаточно HTML-файла.

`dist/engine.js` — независимое ядро (также доступно как CommonJS для тестов), `dist/app.js` — интерфейс, `dist/zip.js` — ZIP/ZIP64 и потоковая распаковка на диск, `dist/demo.js` — демонстрационные данные. После изменения исходников команда `npm run build` пересобирает самодостаточный HTML. Сетевая отправка из приложения дополнительно запрещена Content Security Policy (`connect-src 'none'`); встроенные скрипты самодостаточного файла разрешены только по SHA-256.
